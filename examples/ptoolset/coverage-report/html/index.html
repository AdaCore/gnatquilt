This report presents a global view of the coverage results for the given coverage level. It sums up:
  • the list of trace files processed by gnatcov;
  • the global coverage results;
  • the coverage results per source file.

For each trace file, the following information is given:
  • the name of the trace file;
  • the name of the executable that has been used to generate it;
  • when it has been generated;
  • the tag that has been associated with this run, if any.

The results (total and per file) contain:
  • the total number of lines "of relevance" for the unit (definition blow);
  • the number of such lines that are considered as fully, partially, or not covered for the chosen coverage criteria;
  • the number of such lines that are part of an exemption region, with or without actually exempted violations
  • a visual summary of this coverage data.

"line of relevance" are the source lines that have associated object code and which include all or part of a source entity of interest if we are assessing a source level criterion.
Source comment lines are never included in the counts, typically. In the visual summaries, the colors have the following meaning:

COVERED PARTIALLY_COVERED NOT_COVERED EXEMPTED_NO_VIOLATION EXEMPTED_WITH_VIOLATION
